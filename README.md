# Project: Seeds Of Salvation
### *A Game-Based Approach to Environmental Awareness for the Young Generation through Storyline and Real-World Environment Challenges.*


## 📌 Overview  
This project is a narrative-driven, level-based interactive game designed to raise **environmental awareness** among players, particularly teenagers. It combines storytelling, gameplay mechanics, and visual design to educate users about real-world ecological issues and encourage sustainable thinking.

The game is developed using **Unreal Engine**, featuring multiple levels, animated transitions, and immersive UI/UX elements to create an engaging learning experience.


## 🎯 Objectives  
- Increase awareness about environmental challenges  
- Influence behavioral change through interactive storytelling  
- Provide an engaging and educational gaming experience  
- Encourage players to adopt eco-friendly practices in real life  


## 🛠️ Technologies Used
- **Game Engine:** Unreal Engine
- **Programming:** Blueprint System / C++
- **Design Tools:** UI/UX Design Tools, Graphic Assets
- **Version Control:** Git
